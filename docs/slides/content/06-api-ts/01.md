### Gitlab: Merge Requests (Eröffnung)

- ggf. auf Basis einer bestehenden **Issue** erstellt
  - dabei wird ein **neuer Branch** erstellt (z.B. Name beginnt mit Nummer der Issue)
- auf diesen Branch werden notwendige Änderungen gepusht und diskutiert

- Demonstration: https://gitlab.ti.bfh.ch/w-wseg/26-hs/sandbox/-/issues/35

--

### Gitlab: Merge Requests (Abschluss, teilweise automatisiert)

- häufig ist **Approval** (z.B. Code Review) notwendig:
  - der MR-Branch wird **in `main` gemerget**
  - der MR-Branch wird **gelöscht**
  - die ursprüngliche Issue wird geschlossen

> Bei Github und Bitbucket heissen sie "Pull Requests"

### HTTP-Requests im Frontend

Vue bietet **kein** integriertes HTTP-Handling:

- 👍 [Axios](https://github.com/axios/axios) JS-Bibliothek (siehe [Strapi-docs](https://docs.strapi.io/cms/features/users-permissions#token-usage))
- 👍 Webstandard [fetch()](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API) mit `Promise` (siehe [Strapi-docs](https://docs.strapi.io/cms/api/rest/upload))
- 👎 "Wrapper-Bibliothek" [vue-axios](https://www.npmjs.com/package/vue-axios)
