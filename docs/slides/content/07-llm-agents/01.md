### Meine `.ssh/config` im Homeordner

(Texteditor ohne .txt: Windows 11 > Ansicht > Anzeigen > ✔️ _Dateierweiterungen_ )

```ini
Host *
        ForwardAgent no
        AddKeysToAgent yes
        IdentitiesOnly yes
        # Mac / Linux / Win Powershell
        IdentityFile ~/.ssh/id_ed25519
        # Windows alternativ
        #IdentityFile C:\Users\Joerg\.ssh\id_ed25519

Host nodejs.gruppe.bfh.science
        ProxyJump bkj1@ssh.bfh.science
        User bkj1
        ForwardAgent yes
        # ^ wird leider systemweit deaktiviert :-(
```

Einloggen per `ssh nodejs.gruppe.bfh.science`

Note:
weil /etc/ssh/sshd_config.d/security.conf:AllowAgentForwarding no

x = `Lie on the ocean`; // Backtick

## Funktionen ()

```typescript [1,2,3|5,6,7|10,11]
function addOldSchool(x, y) {
  return x + y;
}

// fat-arrow shorthand
const addFunction = (x, y) => {
  return x + y;
};

//"any": Datentypen angeben!
console.log(addFunction("2", "3"));
```
