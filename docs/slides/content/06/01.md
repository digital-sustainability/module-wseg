### HTTP-Requests im Frontend

Vue bietet **kein** integriertes HTTP-Handling:

- 👍 [Axios](https://github.com/axios/axios) JS-Bibliothek (siehe [Strapi-docs](https://docs.strapi.io/cms/features/users-permissions#token-usage))
- 👌 Webstandard [fetch()](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API) mit `Promise` (siehe [Strapi-docs](https://docs.strapi.io/cms/api/rest/upload))
- 👎 "Wrapper-Bibliothek" [vue-axios](https://www.npmjs.com/package/vue-axios)

### Strapi Login-Funktion (POST)

[A Beginner's Guide to Authentication and Authorization in Strapi](https://strapi.io/blog/a-beginners-guide-to-authentication-and-authorization-in-strapi)

````
const login = () => {
  let json = {
      identifier: loginname.value,
      password: loginpw.value
    }
  axios.post('/api/auth/local', json)
    .then(function (response) {
      // if ok (200)
      authToken = response.data.jwt;
      console.log(authToken);
    })
    .catch(function (error) {
      console.log(error);
    });
};
````

## Funktionen ()

```typescript [1,2,3|5,6,7|10,11]
function addOldSchool(x, y) {
  return x + y;
}

// fat-arrow shorthand
const addFunction = (x, y) => {
  return x + y;
};

//"any": Datentypen angeben!
```
