### Terminalbasics 🧑🏼‍💻 ⌨️

CLI = Command-line Interface<br />
Shell: bash, zsh, pwsh

#### Prompts (Mac/Linux)

- $ == normaler user
- \# == root (superuser)
- ~ == Home-Directory

#### Programm mit Parameter

`$ git version`<br />
`$ node --version`

--

### Verzeichnisse / Pfade

```bash [1|2|3,4|6|7,8|10|11]
ls           # Dateien auflisten
ls -al       # Alle Dateien (auch versteckte) als Detailliste..
mkdir ordner # make directory "ordner"
cd ordner    # change directory (Unterordner)

cd ..        # in übergeordnetes Verzeichnis
pwd          # print working directory
cd           # ins Homedirectory (~) (Mac/Linux)

echo $PATH   # Variable PATH anzeigen (Windows $env:path)
exit         # Shell schliessen
```

- **.dot**-files (oft unsichtbar in Explorer/Finder)

--

### Tasten & Kombinationen

- **up ⬆️ / down ⬇️** (letzte Befehle hervorholen)
- **Tab ↹** (Befehl/Ordner vervollständigen bzw. 2x drücken)
- Aktuelles Kommando beenden: **ctrl + c** (cancel)
- Markierung aus CLI kopieren: **ctrl + shift + c**
- Zwischenablage einfügen: **ctrl + shift + v**
- letzte Befehle suchen: **ctrl + r**

### fnm

- Powershell-Profil (Autostart) anpassen ([Quelle](https://github.com/Schniz/fnm?tab=readme-ov-file#powershell)):

```
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
if (-not (Test-Path $profile)) { New-Item $profile -Force }
Invoke-Item $profile
```

- Diesen Text einfügen und abspeichern:

```
fnm env --use-on-cd --shell powershell | Out-String | Invoke-Expression
```

- Mac zsh:

```
echo 'eval "$(fnm env --use-on-cd --shell zsh)"' >> ~/.zshrc
```
