### Softwarearchitektur

Architektur ist die grundlegende Organisation eines Softwaresystems mit all seinen Komponenten, deren Beziehungen zueinander und zur Umgebung sowie die Prinzipien, die den Entwurf und die Entwicklung des Systems leiten.

> IEEE 1471

Note:
[Softwarearchitektur ist] die Gesamtheit der Entwurfsentscheidungen für ein System (oder Teilsystem), die dessen Entwickler\*innen und Betreibende davon abhält, unnötige Kreativität an den Tag zu legen.

> D’Souza and Wills - Objects, Components and Frameworks with UML: The Catalysis Approach

### Frontend vs Backend

Beide haben eigene Aufgabenbereiche:

- das Frontend
  - präsentiert dem User die Daten
  - bietet Funktionen damit zu interagieren
- das Backend
  - liefert den Datensatz im passenden Kontext
  - gewährleistet Daten-Persistenz unter Beachtung der Geschäftslogik

https://en.wikipedia.org/wiki/Front_end_and_back_end

### GET http://www.example.com/customers/33245

- URLs als Ressourcen Orientierte Architektur
  - Eine Ressource (=Nomen) pro Service, häufig Plural
  - mehrere Operationen (=Verben)
  - Antwortformat: JSON (oder XML)

- Hierarchie: Sammlungen / Collections
  - `GET http://www.example.com/customers/33245/orders`

--

#### [CRUD-Operationen](https://de.wikipedia.org/wiki/CRUD) via HTTP

| Operation | HTTP Verb   |
| --------- | ----------- |
| Create    | POST / PUT  |
| Read      | GET         |
| Update    | PATCH / PUT |
| Delete    | DELETE      |
