#### package manager: [homebrew](https://brew.sh/) installieren 🍺

<div style="font-size: 0.6em !important">

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

</div>

- Befehl kopieren 📋, einfügen und ↵ Enter
- ggf. auf Installation der XCode-CLI-Tools warten
- letzten Schritt erledigen:<br /> _Run these commands in your terminal to add Homebrew to your PATH:_

```
...
```

--

### [Git](https://git-scm.com/download) installieren

```bash
brew install git
```

--

### fnm: [fast node manager](https://github.com/Schniz/fnm)

```bash
brew install fnm
```

<br />

fnm zur Shell-Konfiguration hinzufügen:

```bash
echo 'eval "$(fnm env --use-on-cd --shell zsh)"' >> ~/.zshrc
```

<br />

Aktuelle **long-term support**-Version<br /> von [Node.js](https://www.nodejs.org/) installieren:

```bash
fnm install --lts
```

### Die neue Powershell öffnen

- **Powershell** (pwsh.exe) öffnen per Startmenü + ggf. Suche. _(gibt neues Symbol!)_

<br /><br />

- Ausführung signierter, fremder Programme zulassen

<div style="font-size: 0.9em !important">

### fnm einrichten

- Powershell-Profil (Autostart) anpassen ([Quelle](https://github.com/Schniz/fnm?tab=readme-ov-file#powershell)):

<div style="font-size: 0.9em !important">

```pwsh
if (-not (Test-Path $profile)) { New-Item $profile -Force }
Invoke-Item $profile

```

</div>

- **Diesen Text** in der angebotenen Datei einfügen und **abspeichern**:

<div style="font-size: 0.8em !important">

```pwsh
fnm env --use-on-cd --shell powershell | Out-String | Invoke-Expression
```

</div>

### ... in Gitlab hinzufügen

```bash
cd ~                       # ggf. ins HOME-Directory wechseln
```

```bash
cat .ssh/id_ed25519.pub    # aktuelles macOS
cat .ssh/id_rsa.pub        # macOS 14 (Sonoma) und älter
```

```bash
cat .\.ssh\id_ed25519.pub  # Win
```
